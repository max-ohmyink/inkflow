# Bloomberg Day 2026 × Oh My Ink event presentation

The interface uses the supplied Bloomberg Day 2026 toolkit as the event theme, while the original Oh My Ink logo remains the main brand mark on an unmodified dark contrast field. The exact product name, native identifiers, app icons and platform logo URL are retained. No Bloomberg logo is substituted for Oh My Ink.

The cream canvas, cyan/pink Waterworks poster, yellow actions, heavy geometric headings and tracked wayfinding labels follow the toolkit’s lighter/brighter direction. Two tightly cropped source graphics are used as decorative web elements only; they are never tattoo options or inputs to the tattoo generator. See `event-artwork-provenance.md` for the source-page/crop records and Gabriella Marcella attribution. The confidential full toolkit PDF is not bundled with the application.

## Supplied typography

`Fonts.zip` supplied Avenir Next P for BBG Regular (400), Medium (500) and Demi (600). These files are imported unchanged and loaded through Expo Font as `AvenirNextRegular`, `AvenirNextMedium` and `AvenirNextDemi`. Headings and strong controls use Demi, body uses Regular, and the supplied Bloomberg Prop Unicode I TTF is used for short tracked labels. A dedicated Avenir Next M Bold file was not included, so the app does not claim that unavailable weight. Unused fonts, archive preview HTML and macOS metadata are not bundled. Use of the supplied fonts/artwork remains within the authorized event scope; this document does not grant additional reuse rights.

## Preserved experience

The prompt heading remains **Generate your tattoo live!**. English copy, Art style and Color mix remain; there is no Category selector in the prompt form. New-event tattoo choices are narrowed to simple family-friendly motifs and uncomplicated line directions, while archived designs and source files remain available. The artist’s black/white mirrored stencil remains derived from the original artwork, not the event graphics. Source originals, colored versions, comparison/save controls, history and interrupted-request recovery remain separate.

The supplied physical tattoo-ink swatches are separate from the decorative event palette. Their screen RGB approximations are reference colors, not calibrated physical ink guarantees. Selecting inks does not resolve the earlier image-service restriction: a failed optional color version must still be clearly marked unavailable while usable original artwork remains visible.
