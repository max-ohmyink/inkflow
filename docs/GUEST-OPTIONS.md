# Oh My Ink - Live AI Tattoo Experience — Guest Options

## Your idea, artists’ catalog first

Under **Generate your tattoo live!**, enter a theme and choose Art style and Color mix. There is no form Category selector. The menu offers Fine Line, Old School, Traditional and Watercolor; the unchanged Catalog match default keeps suitable artist-authored originals first before a style is chosen. A blank theme uses Surprise me. Current event work uses the approved nine-design family edit, while the full 451-record import remains for source provenance and history.

Source titles, labels, keywords and supported language aliases determine applicable matches. One to four real catalog matches return without AI padding. Only a valid free-text no-match uses a style-specific AI original, clearly identified as AI-created. Traditional can overlap genuine Old School labels; Watercolor does not invent source styles where no watercolor label exists. Exact ID mismatches do not silently replace a source. Family/mandala exclusions and artist review remain necessary.

## Color that stays with your design

Color mix offers 20 English ink names, choosing up to three. Original colors keeps the source artwork. New custom ink fills run locally without an image provider, using a separate brighter digital mapping while the photo-derived reference values remain unchanged. These screen colors are not calibrated physical ink promises. Black-only remains local monochrome.

The analyzer can repair bounded raster-scale gaps in an internal fill mask to recover more Tiger torso areas; it does not draw new black strokes or paint broad hulls/rectangles. Source dimensions, visible contours and white exterior remain protected. Wide intentional openings remain a limitation. Original, color and original-derived mirrored artist PNG/SVG files stay separate. Ready saved images are not automatically recolored; create a new request for the latest version.

Watercolor is a digital painted-source look. It begins on the untouched original, while a separate selected-ink alternative is explicitly a Flat ink version, not watercolor texture. Staff may simplify the washes for live hand-drawing. New AI source/style creation still needs an available image service; these local color and prompt tests do not establish that the prior restriction is resolved.

## Compare, choose and save

Most guest cards show a ready color version first, with a source-appropriate original comparison. Watercolor starts with the painted original. Saving downloads the explicitly displayed original or alternate. Source title/collection/page are shown only for genuine catalog records. Failed optional colors have no color URL and receive a prominent warning—not a fake successful-color label. The original and working sibling colors remain usable; source-generation/storage failures remain real errors.

Show your choice to our team for the non-permanent, needle-free tattoo moment. The app does not automatically print, notify a staff queue, create a photo, complete a skin try-on or apply a physical tattoo. Artist tools are presentation separation, not authenticated staff access. Printing derives from the source original and mirrors once; test actual equipment and disable additional printer-side mirroring.
