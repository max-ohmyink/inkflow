# Oh My Ink visual reference

The user supplied https://www.ohmyink.com as the visual guideline after the product blueprint was approved. The app follows that reference rather than the initial INKFLOW palette concept.

The homepage inspected on 23 October 2026 uses a near-black background, electric yellow branding and buttons, tall condensed uppercase headlines, italic editorial serif accents, and a high-contrast tattoo-culture identity. The official yellow horizontal logo is reused from the supplied site. The mobile interface translates those cues into a focused event studio: a dark app shell, yellow primary actions, white tattoo artwork surfaces, thin neutral separators, bold step numbers, and restrained rounded controls. The original generated flash artworks are product style examples, not simulated user generation results.
